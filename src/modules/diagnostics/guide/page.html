One-shot probes that write what steward sees in the game to the log or to files, for reporting problems.

What you can do

You want to capture the game's state to attach to a problem report.

Steps
  1. Open the ~Steward~ menu and choose Settings….
  2. Select the Diagnostics group.
  3. Press Run next to a probe, for example "Dump host snapshot" or "Dump kernel state". Each button runs at once and Save is not needed.
Result
The probe writes its lines to the log and the banner at the top of the group shows which probe ran last. See Logs and data folder for where the log is.

You want a file with the buildings, mine buffs or production of the zone you are viewing.

Steps
  1. Open the Diagnostics group on the Settings screen.
  2. In the "This zone" card, press Run next to "Dump buildings", "Dump mine buffs" or "Dump production".
Result
Each of these writes a JSON file into the steward/dumps folder inside the data folder.

You want to record what your generals and army are doing over time.

Steps
  1. In the Diagnostics group, find "Sample generals" in the "Army" card.
  2. Press Start. The button then reads "Stop" with the time left, and a second press stops the sampling.
Result
The sampler takes a reading at a fixed interval for a fixed span; the card shows both next to the button. "Dump generals" and "Dump army" take a single snapshot instead.

The probes are grouped in four cards: Specialists, This zone, Army, and Game data and steward. They only read; the module never sends anything to the game.

Settings

Diagnostics has no settings. Its probes run only when you press a button.

Notes

  • The module does nothing on its own: it never queues work for the game and runs no automation.
  • Dump files can be long and list game objects in detail. Check one before you share it.
