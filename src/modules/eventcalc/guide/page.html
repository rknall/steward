A read-only calculator for the live event: what your explorers bring, how many refills the event fields still need, and which event resources you hold.

What you can do

You want a quick estimate of the event items your explorers will bring.

Steps
  1. Open the ~Steward~ menu, then the Events submenu.
  2. Choose Estimate event items.
Result
A game alert shows the items per day, the items until the item phase ends and how many explorers were counted. Without a live event with explorer items it says so.

You want the full numbers for the running event.

Steps
  1. Open the ~Steward~ menu, then Events, and choose Event calculator…. This opens the dashboard on the Events tab.
  2. Read the "Explorer event items" card (only while such an event is live): explorers counted, items per day and items until they stop.
Result
The estimate takes the best task per explorer. Traits that change the loot count are not included.

You want to know how many refills your event fields still need.

Steps
  1. Open the Events tab as above.
  2. In the "Refill calculator" card read, for each field, Amount, Per 12 h and Refills needed. A "Buffed 12 h" column appears while a field is buffed.
  3. Away from the home island the fields cannot be read: type the amount of each field into its Amount box instead.
Result
Refills needed is what is still missing when the event shop closes. A total row sums every column. Amounts you typed last only until the dashboard is drawn again.

You want to see which event resources you hold.

Steps
  1. Open the Events tab and scroll to the "Event resources" card.
  2. Switch "Only the active event" off to list every event's resources.
Result
A table of Resource, Event and Amount.

Settings

These values are saved with the other steward settings.

routeSeconds

Default: 6

The one-way walk in seconds between an event field and the storehouse. Every produced unit costs a round trip on top of the field's production time. There is no on-screen control for it.

Change it when your fields sit further from or closer to the storehouse than the default assumes.

unitsPerItem

Default: 1

How many deposit units one refill item adds to a field. There is no on-screen control for it.

Change it when an event ships a refill item that adds more than one unit.

heldActiveOnly

Default: On

Shown as "Only the active event" under the "Event resources" table. On lists only the live event's resources; off lists every event's.

Change it when you want to see resources of events that are not running.

Notes

  • The module is a calculator. It never runs on the schedule and sends nothing to the game, so it has no on/off switch.
  • The remaining time is the shop close the event reports; the card has no control for it.
