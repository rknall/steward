Sends your idle explorers on a search for you and picks the search that suits each one.

What you can do

You want idle explorers sent out without sending each one by hand.

Steps
  1. Open the Steward dashboard (Open Dashboard… in the ~Steward~ menu) and select the Explorers tab.
  2. In the Explorers card, turn on Send explorers.
  3. Click Save, and stay on your home island.
Result
Each pass, every idle explorer is sent on the search steward picks for it, one send after another with the Delay between sends pause between them. The module is off until you turn it on, and it only works while you are on your home island.

You want to see what steward would send each explorer before you switch the module on.

Steps
  1. On the Explorers tab, read the Live state table: its columns are Explorer, Status, Current task and Next task.
  2. Use the chips All, Busy, Idle and Overrides to narrow the list.
  3. Under Per-explorer overrides, press Show in log for a fuller dump.
Result
The Next task column shows the search each explorer would get, with an override tag where you fixed one. Show in log writes the same picks, the idle and busy counts and the events it found to the log, and shows a short notice in the game. Nothing is sent by looking.

You want explorers to farm event items during a treasure event.

Steps
  1. Keep Treasure during events on (it is on by default).
Result
While a treasure event is in its content phase, every explorer is sent on a treasure search, also those that would otherwise prefer adventures, and the search with the best items per hour is chosen. A cooldown or a shop-only phase does not count as an event.

You want a different search for explorers that have no special trait.

Steps
  1. On the Explorers tab, open the Default task list.
  2. Pick a search, or Auto (Prolonged baseline) to go back to the longest treasure search.
  3. Click Save.
Result
Explorers without a trait recommendation, and treasure explorers outside an event, use your pick. The list names the game's own searches, treasure and adventure.

Which search an explorer gets

For each idle explorer steward decides in this order, and the first rule that applies wins:

  1. A fixed task you gave that explorer by name (see overrides below).
  2. The default the game itself holds for that explorer type.
  3. The explorer's trait. An explorer that leans toward adventures gets the longest adventure search. One that leans toward treasure gets, during a treasure event, the search with the best items per hour, otherwise a skill search it has learned, otherwise your Default task if it is a treasure search, otherwise the longest treasure search.
  4. An explorer without a trait gets your Default task, then the game's global default, then the longest treasure search.

Settings

These are the settings of the module. Switches and numbers are changed on the Explorers tab and take effect after Save.

enabled

Default: Off

The Send explorers switch. When off, the module sends nothing.

Change it when you want steward to take over, or hand explorers back to yourself.

dispatchDelay

Default: 1500 ms

The Delay between sends: the pause between two explorers sent in one pass. A large roster takes a few minutes at this speed on purpose, so the server is not flooded.

Change it when sends fail or you want a gentler pace.

forceTreasureOnEvents

Default: On

The Treasure during events switch. When on, a treasure event in its content phase pulls every explorer onto a treasure search. When off, the traits decide, even during events.

Change it when you farm adventure items and do not want explorers pulled off adventures.

defaultTask

Default: Auto (the longest treasure search)

The Default task list: the search for explorers with no trait recommendation. You may choose a treasure or an adventure search. Searches that need a learned skill are not in the list, since steward uses them for the explorers that have the skill.

Change it when your plain explorers should do something other than the longest treasure search.

overrides

Default: none

A fixed search per explorer, by the explorer's name. This is the only rule that beats everything else. The screen only counts them under Per-explorer overrides and says they are edited in settings.json; they cannot be set from the tab.

Change it when one named explorer must always do the same search.

Notes

  • Explorers that are busy, or were just sent and have not left idle yet, are skipped. If sends repeatedly change nothing, steward holds the explorer back and pauses sending for a while instead of retrying in a loop.
  • An explorer with an unreadable name or identity is left out of the list.
  • The Overview tab has an Explorers tile with the busy and idle counts and the current default task.
