    This demo set exists to exercise the review shell end to end.

    • Go back to the Settings card page and flip the option bar between Enabled and Disabled.
    • Approve the Settings card page.
    • Come back to this page, write a short comment and press Disapprove.
    • Press Copy feedback and check that the JSON lists both verdicts.
