The steward UI

Steward shows itself in three places: a menu in the client's menu bar, the Steward dashboard and the Steward settings screen.

The ~Steward~ menu

The menu holds, from the top:

  • a pause toggle that reads Steward: ✓ Active or Steward: ✕ Paused; click it to pause or resume all automation at once;
  • a status line, for example how many modules are registered, and, when a dialog has held the action queue for a while, how many minutes it has been held;
  • Open Dashboard…;
  • submenus that some modules add, for example Events, Production, Updates and Adventures;
  • one quick toggle per module that has an on/off switch, shown as ✓ (on) or ✕ (off) before the module's name;
  • Settings….

The Adventures module also adds its own ~Adventures~ entry to the menu bar, right after ~Steward~, for pausing, resuming and ending a run. See Adventures.

The dashboard

Open it with Open Dashboard…. Its title is Steward. The header shows a badge (Running or Paused) and a one-line summary. Under it is a tab bar, then one panel with the selected tab.

The tabs are Overview, then Explorers, Geologists, Mining, Collect, Events and Production. A tab is shown only when a module belongs on it. A tab carries a dot when one of its modules has an on/off switch (lit while a module is on and steward is not paused) and a mark while a module there has unsaved changes.

The Overview tab shows:

  • Automation, the master switch. It pauses at once: it is the pause, not a setting;
  • Queue, the number of actions waiting;
  • the check interval and Build, the version you run;
  • one tile per module that has one. The tile switches are ordinary settings and wait for Save.

On a module tab, the module's settings stand in a column beside its main area. In a small window that column folds into a one-line strip with a Show settings link (and Hide settings to fold it again).

Save and Close

Changes you make on the dashboard or the settings screen are kept in a buffer. Nothing applies until you press Save; Close throws the changes away. The footer says No changes. Settings apply when you press Save. while the buffer is untouched, and otherwise counts the changes. Only the pause switch on the Overview acts at once.

The settings screen

Open it with Settings… in the ~Steward~ menu. Its title is Steward settings. A navigation list on the left shows one group at a time on the right:

  • General: the Logging and Scheduler cards and an About card with the build and the data folder. See Logs and data folder;
  • one group per module that has no dashboard tab of its own (Adventures, Diagnostics and Updates).

In the Scheduler card, Check for work every sets how often steward looks for something to do. It accepts at least 10 seconds. A lower value is faster but busier.

Modules whose buttons act at once, such as Diagnostics, are listed under RUNS AT ONCE; Save does nothing for them.
