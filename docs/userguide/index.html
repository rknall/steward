Overview

Steward is an add-on for the Adobe AIR 32 client of The Settlers Online that automates routine work for you: it picks up collectibles, sends specialists out, runs adventures and keeps production busy.

What steward is

Steward is one userscript file, user_steward.js, that the client loads next to its own scripts. It runs inside the client, so it works on the game you already have open and needs no second program. Every kind of automation is a separate module that you can switch on or off on its own.

Steward does nothing until you have installed it (see Installing). Once it is loaded, a ~Steward~ menu appears in the client's menu bar, and everything is controlled from there and from two windows (see The steward UI).

The modules

Each module has its own page with use cases, its settings and notes.

  • Adventures: runs adventure templates and scenario files as a series of maps, from home back to home, with pause and resume.
  • Collect Pickups: clicks map pickups on the home island and the quest objects that open quests wait for on adventures.
  • Diagnostics: read-only probes on the Settings screen that write kernel, host and specialist state to the log.
  • Event calculator: read-only event calculator, an explorer event-item estimate and a refill calculator for event fields.
  • Explorers: sends idle explorers to the task the precedence chain picks.
  • Geologists: sends idle geologists to deposit-search tasks, up to the wanted number of deposits per type.
  • Mining: builds, upgrades, pauses and buffs the mines and masons on the home island.
  • Production: keeps the timed production queues of the home island busy with automatic orders and buffs.
  • Updates: checks GitHub Releases, installs a chosen release and steps down to an older one.

Where to start

  1. Install the script and reload scripts: Installing.
  2. Learn the menu, the dashboard and the Settings screen: The steward UI.
  3. Pick the modules you want and read their pages.
  4. If something does not work, see Troubleshooting and Logs and data folder.
