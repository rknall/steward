Installing

Installing steward means copying one file into the client's userscripts/ folder and reloading scripts.

First install

The first install is manual. After it, steward can update itself (see Updates).

You want steward running in your client.

Steps
  1. Download user_steward.js from the latest release on the steward GitHub page.
  2. Put the file in the userscripts/ folder of your TSO client (<TSO client folder>/userscripts/).
  3. Reload scripts from the client menu, or restart the client.
Result
The ~Steward~ menu appears in the client's menu bar.

What the client does with the file

The client loads its own scripts first and then every file in userscripts/. Reloading scripts loads the file again: the new copy of steward stops the old one before it starts, so you never run two at once.

The client's scripts manager can switch single userscripts on and off. If steward is switched off there and scripts are reloaded, no new copy is loaded, and an already running copy stays alive until you restart the client.

Where the menu appears

The client's menu style decides the place. With the default grouped style ~Steward~ sits in the menu bar itself. With any other style it is nested in the client's Tools menu.

Where steward keeps its files

Steward writes its logs, dumps and adventure templates to a steward/ folder inside the client folder. See Logs and data folder.
